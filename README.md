`main.py` (pure Python stdlib, no third-party libraries) writes exactly one word to `/output/entry.txt` — the single word that describes the whole internet. The output is deterministic: every run produces byte-identical output.

> Cookies

Every site on the internet begs you to accept cookies — the whole web runs on them, and the word itself is warm, funny, and instantly readable.

## Run it

```sh
python3 main.py
```
